# 新Codex Cloud実践マニュアル [![CC BY 4.0](https://i.creativecommons.org/l/by/4.0/88x31.png)](https://creativecommons.org/licenses/by/4.0/)

**AIによる文書作成・コード作成・共同作業（2026年11月17日版）**

2026年9月に刷新された **新Codex Cloud** を活用し、ローカル環境構築なしでGitHubリポジトリを起点とした調査・実装・テスト・プルリクエスト（PR）作成・共同文書保守を行うための実践ガイドです。

## 📖 マニュアルを読む

* **[新Codex Cloud実践マニュアル（日本語版）](./codex-cloud-manual-ja.md)**

## 主な内容
1. GitHubリポジトリからCloud環境を作成する
2. 環境をPublishして再利用する
3. Codexにソースコードや文書の作成・変更を依頼する
4. 差分（diff）とテスト結果を確認する
5. PRを作成し、GitHubでレビュー・マージする
6. 日本語・英語のマニュアル文書を更新する（`AGENTS.md` の活用）
7. 別端末から同じタスクを再開する
8. 環境設定を変更してRepublishする
